# Why only Windows?

People sometimes suggest that SumatraPDF should be available for other operating systems, such as Linux, macOS, and Android.

This won't happen.

The first reason is that the current developers don't know how to write software for those other platforms.

The second reason is that it would mean writing the whole program from scratch for a new platform.

SumatraPDF is tightly integrated with and optimized for Windows. Making a version for another operating system would not be a matter of making a few changes here and there; it would require writing all the UI code from scratch, i.e. redoing years of development that went into SumatraPDF.

SumatraPDF is an open-source project, so anyone is free to use our source code to create an equivalent application for another operating system, but we're unlikely to do it ourselves.
