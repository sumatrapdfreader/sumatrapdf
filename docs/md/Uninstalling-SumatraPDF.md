# Uninstalling SumatraPDF

## Are you using an official SumatraPDF build?

Did you download SumatraPDF from the [official SumatraPDF website](https://www.sumatrapdfreader.org/download-free-pdf-viewer)?

If not, we can't help you because we didn't create the software you're using.

## Uninstalling Sumatra

There are two versions of SumatraPDF: an installer and a portable version (zipped executable).

## Uninstalling portable version

If you're using the zipped executable, you only need to delete `SumatraPDF.exe`.

## Uninstalling the installer version

If you installed SumatraPDF by running the official installer, uninstall it like any other application.

On Windows 10 / 11:

- start the Settings app ([instructions](https://www.digitalcitizen.life/introducing-windows-10-ways-open-settings))
- select `Apps`
- find `SumatraPDF` in the list, click it, and press the `Uninstall` button:

![Uninstall](img/uninstall.png)
