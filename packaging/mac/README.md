# SumatraPDF for macOS

This archive contains an early native macOS reader. Move `SumatraPDF.app` to `/Applications` or run it in place.

The application can open supported documents from Finder, **File → Open**, or the command line:

```sh
open SumatraPDF.app --args /path/to/document.pdf
```

This development build is not signed or notarized. macOS may require explicit approval before it runs.
